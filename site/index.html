The mission loop

Done is an agreement, not a declaration.

You state the objective. AbsoLoop writes a checkpointed contract and closes the loop only when the proof survives review.

  1. 01 Objective

    State the outcome in plain language.

  2. 02 /goal

    A contract names the evidence, the budget, and done.

  3. 03 Builder

    Repair, test, and escalate thinking when stuck.

  4. 04 Critic

    Read-only review that tries to disprove the result.

  5. 05 Human gate

    Approve, reject, resume, or extend.

Why it holds

Local agents. Hard edges.

No cloud AbsoLoop service. No mystery SaaS. Your machine, your providers, your ledger.

Evidence
Narratives and “looks good” diffs are not acceptance. The contract names the proof.
Critic
An independent reviewer tries to break the result before it reaches you.
Budgets
Iterations, wall clock, and dollars stay visible. Stop safely, then resume or extend.
Providers
Grok, Claude Code, and Codex keep their own authentication, tools, and sessions.
Runtime
Python 3.9 and the standard library. Nothing to pip install for the core CLI.
Price
Free. MIT licensed. No subscription and no AbsoLoop account.

Quick start

Start a loop on your machine.

Bring Python 3.9+ and at least one provider CLI: Grok, Claude Code, or Codex. AbsoLoop keeps the tools and the login you already use.

Full setup guide
mission-prep Ready 
$ git clone https://github.com/MoRohn/absoloop.git
$ cd absoloop
$ export PATH="$PWD/bin:$PATH"
$ absoloop setup
$ absoloop "Make all tests pass"
